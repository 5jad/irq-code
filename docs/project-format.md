# صيغة مشروع IRQ التجريبية

`irq-project` يحمّل قائمة ملفات مصدر صريحة من `irq.toml`. هذا الإصدار يتعامل مع **جزء محدود وصارم من TOML**، وليس parser عاماً لـTOML؛ يجب رفض أي مفتاح أو بنية غير موثقة بدلاً من تجاهلها.

```toml
[package]
name = "demo"
sources = ["src/main.irq", "src/math.irq"]
```

القيود الحالية:

- `name` مطلوب ويجب أن يكون identifier ASCII.
- `sources` مطلوب وغير فارغ، ومصفوفة نصوص في سطر واحد؛ لا تدعم عناصر escaped أو multiline.
- كل مصدر مسار نسبي تحت جذر المشروع بامتداد `.irq`، ولا يقبل `.` أو `..` أو المسارات المطلقة.
- تُحل المسارات canonicalize وتُرفض المصادر التي تشير خارج الجذر عبر symlink.
- الملفات تُقرأ بحد حجم المصدر المعتمد في lexer، وعدد الملفات محدود بـ1024.
- ترتيب الوحدات هو ترتيب `sources` في manifest، وأسماء الوحدات المكررة مرفوضة.
- لا يطبق هذا التحميل بعد `use` أو حل الرموز بين الوحدات أو قواعد `pub`؛ هذه بوابات مفتوحة في المرحلة الثالثة، كما أن `use` والوحدات المتعددة ليستا ضمن IRQ 0.1 المعياري الحالي.

هذه الصيغة أولية وغير مستقرة؛ لا تستخدمها كواجهة توافقية لإصدار 1.0. كما أن فحص canonical paths هنا حماية من المسارات/الروابط الخارجة المعتادة، وليس ضماناً ضد خصم يبدل نظام الملفات بالتزامن أثناء التحميل.
