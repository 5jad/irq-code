# سجل قرارات تصميم IRQ

## القرارات المثبتة لـIRQ 0.1

التفاصيل المعيارية والأمثلة في [`irq-0.1-language-spec.md`](irq-0.1-language-spec.md). العلامة `[x]` تعني أن قرار التصميم محسوم، ولا تعني أن المترجم نفّذه.

- [x] **تنفيذ المترجم:** Rust؛ اللغة مستقلة دلالياً عن Rust، وRust backend مؤقت.
- [x] **نحو المترجم:** lexer يدوي، parser تصريحي/كتلي recursive-descent عند استكماله، وPratt expressions؛ لا اعتماد على PEG runtime في 0.1. الـparser السطري الحالي مرحلة انتقالية وليس قرار grammar.
- [x] **نطاق 0.1:** ملف ووحدة واحدة، دوال محلية، أنواع `i32/u32/i64/u64/bool/str/()`, `if/else`, `while`, `return`, ونتائج صريحة؛ لا `use`, `const`, `struct`, `enum`, fields, refs, collections, floats, FFI, أو IO.
- [x] **الأسماء:** ASCII identifiers بالنمط `[A-Za-z_][A-Za-z0-9_]*`, حساسة للحالة؛ قواعد الكلمات المحجوزة والترتيب والمسافات محددة في المواصفة.
- [x] **الرؤية:** `pub fn` للتصدير، و`fn` خاصة؛ لا وصول لحقول أو وحدات متعددة في 0.1.
- [x] **القيم والملكية:** scalars وunit بالقيمة؛ `str` UTF-8 immutable value؛ لا null، references، borrowing، clone API، أو ادعاء memory safety. الأنواع المركبة مؤجلة.
- [x] **الحساب:** العمليات الصحيحة checked؛ Overflow وDivisionByZero أخطاء IRQ؛ القسمة نحو الصفر والباقي بإشارة المقسوم؛ `MIN / -1` و`MIN % -1` Overflow. لا floats ولا implicit casts.
- [x] **`+%` و`+?`:** غير مدعومين وغير معرفين في 0.1؛ أي معنى مستقبلي يتطلب قراراً ومواصفة واختبارات جديدة.
- [x] **الأخطاء:** النموذج المستهدف `Result<T,E>`، وصياغة return مختصرة `T | err(...)`، مع `ok`, `err`, `try`, و`match` شامل. النتيجة القابلة للفشل لا تُسقط. هذه فجوة تنفيذ حالية موثقة.
- [x] **العقود:** `requires`/`ensures` annotations غير فعّالة في 0.1؛ لا runtime enforcement ولا SMT proof. `old(x)` مؤجل ومحجوز. لا تعتمد أي ضمان أمني عليها.
- [x] **الآثار والقدرات:** profile 0.1 pure و`reads/writes: none` فقط. التصريح ليس sandbox. تصميم IO المستقبلي يستخدم قدرات صريحة مع فحص أثر ساكن وإنفاذ runtime/OS واختبارات traversal/symlink/TOCTOU.
- [x] **أمثلة القبول والرفض:** مثبتة في المواصفة؛ أمثلة المنفذ فعلياً واختباراته منفصلة عن الأمثلة المعيارية للميزات المؤجلة.
