# معمارية IRQ 0.1 — خطة التنفيذ

المرجع المعياري لقرارات اللغة هو [`irq-0.1-language-spec.md`](irq-0.1-language-spec.md). يصف هذا المستند مسار المترجم والحدود التنفيذية؛ لا تنتقل ميزة إلى حالة «منفذة» قبل وجود اختبار.

## القرار المعماري: Rust للتنفيذ، واستقلال دلالة IRQ

Rust مناسب لبناء compiler لما يقدمه من أنواع وأدوات واختبار. لا ترث IRQ ضمانات Rust تلقائياً. Rust backend مؤقت، ويجب أن تظل دلالة المصدر AST/HIR مستقلة عن backend كي يمكن استبداله. لا يُسمح بمصدر Rust خام أو `unsafe` صادر من المستخدم ضمن profile الآمن.

## تدفق المترجم المستهدف

`source -> lexer/source map -> parser -> AST -> name/type/flow checks -> effect checks -> HIR -> backend -> runtime/capability boundary`

المراحل المفقودة لا تُعرض في واجهة CLI كأنها منفذة. parser السطري الحالي انتقال مؤقت إلى grammar المعيارية؛ ويجب أن تتبع أي توسعة قواعد `docs/irq-0.1-language-spec.md` وتحدّث `implemented-subset.ebnf` والاختبارات.

## حدود IRQ 0.1

الـprofile المعياري أحادي الوحدة ويضم أنواع القيم الأساسية، دوالاً محلية، أخطاء صريحة، `if/else` و`while`. لا يضم `use`, `const`, `struct`, `enum`, `match` في تنفيذ compiler الحالي، collections، المراجع المخصصة، floats، FFI، أو IO. قد تحدد المواصفة الدلالة المستهدفة قبل تنفيذها؛ ويجب أن يظل فرق التنفيذ معلناً.

تصريحات `reads/writes` لا تمنع النظام من الوصول إلى الموارد. عند إضافة IO، نحتاج تحليل آثار ساكن عابر للاستدعاءات **و**تمرير capabilities صريحة وإنفاذاً عند runtime/OS. لا يوصف التقرير الساكن بأنه sandbox. حماية المسارات والروابط الرمزية وTOCTOU وحدود CPU/ذاكرة/وقت شروط قبل ادعاء العزل.

## العقود والنتائج

`requires` و`ensures` annotations غير فعّالة حالياً؛ لا يوجد SMT أو runtime contract evaluator. نتيجة `Result` المصدرية و`try/ok/err/match` معرفة في المواصفة كهدف لكن غير منفذة في compiler الحالي. لا يساوي `Result` الداخلي في Rust backend نظام الأخطاء المصدرّي الكامل.

## معايير قبول المعمارية

يُقبل كل طور عند وجود pass/fail fixtures، وتشخيصات قابلة للاختبار، وتوافق بين grammar والـAST والفاحص والـbackend. لا يُقبل ادعاء أمني دون اختبار يثبت أن المسار المقصود يمنع الانتهاك؛ وتظل صحة المنطق ومسؤولية المكتبات الخارجية خارج ما يثبته نجاح الترجمة وحده.
